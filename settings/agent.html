    How it works & privacy
    

      
      

        Still local-only. With the switch on, Scorly keeps one connection open to
        ws://127.0.0.1:47615, on this computer, where only Scorly's agent tool listens.
        For each audit it opens the URL in a background tab, runs the same analysis as the popup and closes the tab.
        With the switch off, agents can still use Scorly, but audits run in a separate headless Chrome without your logins.
      

    

    

      
scorly_audit

      
Scores plus every failing check and warning, with the reason. Re-auditing the same URL adds what changed.

      
scorly_compare

      
A field-by-field diff of two audits, using the same engine as the Compare view.

      
scorly_status

      
Whether audits run in this browser or in headless Chrome.

    

    
Some checks depend on hosting, not code (HTTP/2, security headers), so they can't pass on a local dev server. Background-tab audits record no LCP/CLS, so before/after comparisons leave those timings out.

    Troubleshooting
    
    
      
  • Stuck on "Waiting for an agent": no agent session with Scorly is running. Start one; Scorly checks every 30 seconds, or press Retry now.
    • 
      
  • "SCORLY NOT INSTALLED" or setup not detected: in a terminal, npx -y github:dazecoop/scorly status lists each agent app, whether Scorly is installed there and whether it starts. Detection on this page also needs the switch on and an agent session running.
    • 
      
  • Audits run headless even though the switch is on: check that the port matches SCORLY_PORT in your agent config, and that Only allow localhost URLs isn't blocking the URL.
    • 
      
  • Headless fails to start: install Google Chrome, or set SCORLY_CHROME to a Chrome/Chromium binary.
